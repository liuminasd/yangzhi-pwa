仰止AI — 隐私政策

更新日期：2026年8月9日

1. 数据收集

仰止AI 是本地优先的 PWA 应用。您的聊天记录、个人设置和记忆数据完全存储在本设备（IndexedDB / localStorage），不会自动上传到任何服务器。

2. API 调用

当您发送消息时，应用会将消息内容发送到您配置的 AI API 端点（如 DeepSeek API）以获取回复。在此过程中：

  • 仅发送当前对话上下文，不包含设备标识
  • API Key 仅存储在本设备本地存储中
  • 不经过本应用的任何中间服务器

3. 数据导出与删除

您可以在设置中导出全部数据（支持 AES-256-GCM 加密），也可以随时清除所有本地数据，操作不可逆。

4. 第三方服务

  • Tesseract.js OCR 引擎按需从 CDN 加载，仅处理您主动上传的图片，处理后文本仅存储于本地
  • 应用使用 Service Worker 缓存静态资源以支持离线使用

5. 权限说明

  • 网络访问：用于调用 AI API 和加载 OCR 引擎
  • 存储：用于本地数据持久化和离线缓存
  • 不请求摄像头、麦克风、位置、通讯录等敏感权限

6. 儿童隐私

本应用不面向 13 岁以下儿童，不会有意收集儿童个人信息。
